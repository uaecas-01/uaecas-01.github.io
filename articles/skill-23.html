복습법문제

같은 문제집을 여러 번 풀면 답을 외워버리는데, 2회독은 어떻게 해야 효과적일까?

⏱ 5분 읽기2026.10

문제집을 다시 풀어보려고 펼쳤는데, 문제를 보기 전에 답이 먼저 떠오르는 경험을 해본 학생이 많습니다. 분명 한 번 풀었던 문제라 익숙한 건 당연하지만, 이 상태로 2회독을 하면 정작 실력이 늘었는지 확인하기가 어려워집니다.

답을 외운 것과 풀이 과정을 이해한 것은 다릅니다

2회독의 목적은 답을 다시 맞히는 것이 아니라, 그 문제를 푸는 과정과 사고의 흐름을 다시 점검하는 것입니다. 답만 외워서 맞혔다면 실제로는 아무것도 확인되지 않은 것과 같습니다. 2회독을 할 때는 답이 아니라 '왜 이렇게 풀었는지'를 소리 내어 설명할 수 있는지를 기준으로 삼아야 합니다.

답을 가리고 풀이 과정만 먼저 적어보세요

문제를 다시 풀 때는 답과 이전에 적어둔 풀이를 가린 채, 빈 종이에 처음부터 풀이 과정을 다시 적어보세요. 과정을 다 적은 뒤에 이전 풀이와 비교하면, 답은 맞았지만 과정에서 다르게 접근했거나 헷갈렸던 부분이 드러납니다.

순서를 바꿔서 풀어보는 것도 방법입니다

문제 순서를 기억해서 답을 떠올리는 경우가 많다면, 문제집의 순서를 무작위로 섞어서 풀거나, 단원별로 흩어놓고 섞어서 풀어보세요. 순서에 의존한 암기를 줄이고, 문제 자체를 다시 분석하게 만드는 효과가 있습니다.

오히려 틀렸던 문제보다 맞혔던 문제를 더 점검하세요

이미 틀렸던 문제는 보통 한 번 더 신경 써서 다시 봅니다. 하지만 맞혔던 문제 중에서도 '정확한 이해 없이 감으로 맞힌' 문제가 섞여 있을 수 있습니다. 2회독에서는 맞힌 문제라도 풀이 과정을 짧게라도 다시 설명해보고, 설명이 막히는 문제는 틀린 문제와 똑같이 취급해 다시 정리해야 합니다.

효과적인 2회독 방법: 답과 이전 풀이를 가리고 과정부터 다시 적어보기 · 문제 순서를 섞어서 풀어보기 · 맞힌 문제도 풀이 과정을 설명할 수 있는지 점검하기 · 설명이 막히는 문제는 틀린 문제처럼 다시 정리하기.

문제집을 여러 번 보는 이유는 같은 답을 여러 번 확인하기 위해서가 아니라, 풀이 과정이 온전히 내 것이 되었는지를 확인하기 위해서입니다. 답이 먼저 떠오른다고 해서 2회독을 그만둘 필요는 없습니다. 방법만 조금 바꾸면 오히려 가장 효율적인 복습이 됩니다.
